## About Me

CS student and AI engineer passionate about building real-world machine learning systems. I compete in datathons, build LLM-powered tools, and turn research papers into working software.

- Currently building: **[github-rag-assistant](https://github.com/tursuntalha/github-rag-assistant)** — local RAG system for GitHub repositories, and **[SQLbot](https://github.com/tursuntalha/SQLbot)** — a Turkish Text-to-SQL chatbot powered by local LLMs
- Interests: RAG pipelines, NLP, computer vision, gradient boosting for tabular data
- Hackathon competitor: BTK, Haier, Trendyol, Pusula, NMI-ACUHIT
