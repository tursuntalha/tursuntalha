## About Me

CS student and AI engineer who builds real-world systems — not just notebooks. I work across the full stack of ML: from data wrangling and gradient boosting in datathon competitions, to RAG pipelines and local LLM systems, to full-stack web apps.

- **Currently building:** [`github-rag-assistant`](https://github.com/tursuntalha/github-rag-assistant) (local RAG for GitHub repos), [`SQLbot`](https://github.com/tursuntalha/SQLbot) (Turkish Text-to-SQL chatbot), and [`TurkBench`](https://github.com/tursuntalha/yl) (Turkish LLM evaluation framework)
- **Hackathon record:** BTK Academy (career prediction), Haier Datathon (0.96214 public score), Trendyol (search ranking), NMI-ACUHIT (Turkish NLP), Pusula (medical data)
- **What drives me:** Local LLMs (Ollama ecosystem), Turkish NLP, privacy-preserving AI, and systems that work without API keys
- **Interests:** RAG pipelines, LLM fine-tuning with LoRA, computer vision, gradient boosting for tabular data
